# Готовка — что приготовить?

Приложение подсказывает, что приготовить из продуктов, которые есть дома. 2000 рецептов, калории, дневная норма (от 14 лет), рацион на день, фильтры по калориям, кухням и типам блюд. Работает без интернета и устанавливается на телефон как приложение.

Это обычный сайт из статических файлов, сервер и сборка не нужны. Бесплатно размещается на **GitHub Pages**.

---

## Что в папке

```
index.html              само приложение (всё в одном файле)
manifest.webmanifest    данные для установки на телефон
sw.js                   работа без интернета
.nojekyll               отключает обработку Jekyll на GitHub Pages
img/
  favicon.svg           иконка вкладки браузера
  icon-192.png          иконка приложения
  icon-512.png          иконка приложения
  apple-touch-icon.png  иконка для iPhone
README.md               эта инструкция
```

Все файлы должны лежать именно так, `index.html` в корне репозитория, а иконки в папке `img`.

## Способ 1. Через сайт GitHub, без программ (проще всего)

### Шаг 1. Аккаунт
Зарегистрируйтесь на https://github.com (если аккаунта ещё нет) и подтвердите почту.

### Шаг 2. Создайте репозиторий
1. Нажмите **+** в правом верхнем углу, затем **New repository**.
2. В поле **Repository name** введите имя, например `gotovka` (латиницей, без пробелов). Оно попадёт в адрес сайта.
3. Выберите **Public**. Для бесплатного GitHub Pages репозиторий должен быть публичным.
4. Галочки (README, .gitignore, license) **не ставьте**.
5. Нажмите **Create repository**.

### Шаг 3. Загрузите файлы
1. На странице нового репозитория нажмите ссылку **uploading an existing file**.
2. Распакуйте архив `gotovka.zip` на компьютере.
3. Откройте распакованную папку и **выделите всё её содержимое**: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, папку `img` и файл `.nojekyll`. Перетащите всё в окно браузера.
4. Дождитесь, пока загрузка завершится, и нажмите **Commit changes**.

> Если файл `.nojekyll` не виден в проводнике, включите показ скрытых файлов (Windows: Вид → Показать → Скрытые элементы; Mac: Cmd+Shift+точка). Без него сайт обычно всё равно работает, так что это не критично.
>
> Папку `img` браузер должен загрузить вместе с файлами внутри. Если в репозитории появилась только пустая папка или её нет, загрузите файлы из `img` отдельно: **Add file → Upload files**, и в поле имени перед файлом укажите путь `img/`. Проще использовать способ 2.

### Шаг 4. Включите GitHub Pages
1. В репозитории откройте **Settings** (вкладка справа сверху).
2. В левом меню выберите **Pages**.
3. В блоке **Build and deployment** → **Source** выберите **Deploy from a branch**.
4. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.

### Шаг 5. Откройте сайт
Подождите 1–3 минуты и обновите страницу **Settings → Pages**. Сверху появится надпись *Your site is live at…*. Адрес такой:

```
https://ВАШ_ЛОГИН.github.io/gotovka/
```

Откройте его с телефона и компьютера, приложение готово.

## Способ 2. Через Git (командная строка)

Нужен установленный Git (https://git-scm.com). Сначала создайте пустой репозиторий на GitHub, как в шагах 1–2 выше, затем в терминале:

```bash
cd путь/к/папке/gotovka

git init
git add .
git commit -m "Первая версия приложения"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/gotovka.git
git push -u origin main
```

GitHub попросит войти. Вместо пароля используйте **Personal Access Token** (GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → отметьте `repo`). После загрузки выполните шаги 4–5.

## Установка на телефон как приложения

- **iPhone (Safari):** откройте сайт, нажмите кнопку «Поделиться», затем **На экран «Домой»**.
- **Android (Chrome):** откройте сайт, нажмите меню ⋮, затем **Установить приложение** или **Добавить на главный экран**.
- **Компьютер (Chrome/Edge):** в адресной строке справа появится значок установки.

После первого открытия приложение работает и без интернета.

---

## Как обновить приложение

1. Откройте файл в репозитории (например, `index.html`), нажмите значок карандаша ✏️ или **Add file → Upload files** и загрузите новую версию с тем же именем.
2. Нажмите **Commit changes**. Через 1–2 минуты сайт обновится.
3. Если у кого-то всё ещё старая версия, откройте `sw.js` и поменяйте номер версии: `gotovka-v1` на `gotovka-v2` (потом `v3` и так далее). Тогда телефоны скачают свежие файлы. Обычно достаточно закрыть и снова открыть приложение 1–2 раза.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Ошибка **404** по адресу сайта | Подождите пару минут. Проверьте, что `index.html` лежит в корне репозитория, а не внутри вложенной папки, и что в Settings → Pages выбрана ветка `main` и `/ (root)`. |
| Пустая страница | Откройте консоль браузера (F12) и посмотрите на ошибки. Проверьте, что `index.html` загружен целиком (размер около 1 МБ). |
| Нет иконки или не ставится как приложение | Проверьте, что папка `img` и `manifest.webmanifest` загружены, а имена файлов написаны строчными буквами. GitHub различает регистр. |
| Не обновляется после замены файла | Обновите страницу с очисткой кэша (Ctrl+Shift+R) или увеличьте номер версии в `sw.js`. |
| Пункт Pages не активен | Репозиторий должен быть **Public**. |

## Свой адрес (по желанию)

В **Settings → Pages → Custom domain** можно указать свой домен. GitHub подскажет, какие DNS-записи нужно создать у регистратора домена.

## Заметки о приложении

- Все данные (продукты, избранное, рацион, профиль) хранятся только в браузере пользователя и никуда не отправляются.
- Калории рассчитываются приблизительно по сырым продуктам. Дневная норма считается по формуле Миффлина — Сан-Жеора и не заменяет консультацию врача. Для 14–17 лет это примерная оценка, и цель «похудеть» там не применяется.
- Тип блюда (суп, салат, десерт и т. д.) определяется по названию, поэтому в редких случаях возможны неточности.
